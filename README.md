# Modaber — Smart Money Management

An interactive personal finance dashboard (not a landing page), built with vanilla **HTML5**, **CSS3**, **Bootstrap**, and **JavaScript**.

🔗 **Live Demo:** https://mahmoudahmed992005.github.io/Modaber/

## ✨ Features

- 💰 Balances overview
- 💳 Transactions log
- 📅 Budgets
- 🧾 Monthly bills
- 📉 Weekly cash flow (FinTech-style UI)

## 🛠️ Tech Stack

| Category | Technology |
|---|---|
| Markup | HTML5 |
| Styling | CSS3, Bootstrap |
| Interactivity | JavaScript |

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/Mahmoudahmed992005/Modaber.git

# Navigate into the project
cd Modaber
```

### Run

No build step required — just open `index.html` directly in your browser, or serve it with a live server:

```bash
# Using VS Code Live Server extension, or:
npx serve .
```
